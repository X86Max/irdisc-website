IRdisC follows a simple idea: keep the terminal, and make IRC easier to discover.

The [project philosophy](https://github.com/X86Max/IRdisC#project-philosophy) describes the goal: reduce the barrier for new IRC users without a heavy GUI or hiding the commands experienced users already know.

## IRC, discomplicated.

- Keyboard access stays complete; the mouse is optional.
- Menus and built-in help make commands easier to discover.
- The client stays lightweight, with no third-party runtime Python dependencies.

Extract the source archive, open its directory, and run:

```bash
python3 irdisc.py
```

See the [installation instructions](./index.html#download) for requirements and other installation methods. The Web Terminal also provides an `install` command.
